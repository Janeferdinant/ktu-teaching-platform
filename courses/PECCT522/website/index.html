Module 1 • Recurrence & Complexity KTU High-Yield • 9 Marks

Problem 1: Solve the Recurrence Relation T(n) = 2T(n/2) + Θ(n) using Master Theorem & Substitution

Given: A divide-and-conquer algorithm partitions an input of size n into 2 equal subproblems, recursively solves each half, and performs linear work cn for combining results.

Step 1: Identify Parameters for Master Theorem:
General form: T(n) = a T(n/b) + f(n) • Here: a = 2, b = 2, f(n) = Θ(n).
Step 2: Compute the Critical Exponent log_b(a):
log_b(a) = log_2(2) = 1 ==> n^{log_b(a)} = n^1 = n
Step 3: Compare f(n) with n^{log_b(a)}:
Since f(n) = Θ(n^{log_b(a)} * log^k(n)) with k = 0, this falls strictly into Master Theorem Case 2.
Solution: T(n) = Θ(n^{log_b(a)} * log^{k+1}(n)) = Θ(n log n)
Module 2 • Memory Management KTU High-Yield • 9 Marks

Problem 2: External Fragmentation & Dynamic Allocation Equations

Given: Dynamic memory heap contains fragmented free holes: 120 KB, 80 KB, 160 KB, and 140 KB. Total free memory = 500 KB.

Step 1: Allocation Request Analysis:
For a request of size 200 KB, maximum contiguous free block = 160 KB < 200 KB. The request FAILS despite 500 KB total free memory.
External Fragmentation Ratio = 1 - (Max Contiguous Free Block / Total Free Memory) = 1 - (160 / 500) = 0.68 (68%)
Module 3 • Trees & Heaps KTU High-Yield • 9 Marks

Problem 3: Mathematical Proof of O(n) Build-Heap Time Complexity

Step 1: Formulate Total Work Done by Max-Heapify:
Total Time T(n) = Σ_{h=0}^{⌊log n⌋} ⌈n / 2^{h+1}⌉ * O(h) = O(n * Σ_{h=0}^{∞} h / 2^h)
Since Σ_{h=0}^{∞} h / 2^h = 2 ==> T(n) = O(n * 2) = O(n) (Linear Time)

Real-Life Industry Engineering Applications

Production systems engineering architectures bridging theoretical principles of BLOCKCHAIN AND CRYPTOCURRENCY to modern enterprise computing.

Module 1 • Systems Architecture

Web Browser Navigation & Multi-Level Undo Engine

Modern web runtimes and graphical software deploy dual LIFO stacks to enable instantaneous constant-time O(1) state undo and redo navigation while bounding buffer memory.

Module 2 • Operating Systems

Kernel Memory SLAB Allocator & Stream Buffers

Operating system memory managers implement SLAB allocation caches (First-Fit / Best-Fit algorithms) to eliminate external fragmentation, while media pipelines rely on Circular Linked Buffers.

Module 3 • Autonomous Routing & DBs

OSPF Network Routing & Database B+ Tree Indexing

Enterprise internet backbones deploy Dijkstra's algorithm over graph meshes for low-latency packet routing. Relational database engines rely on balanced B+ Tree search structures for O(log n) queries.

Module 4 • Distributed Systems

Distributed In-Memory Cache & Symbol Tables

Distributed caching platforms (Redis, Memcached) use consistent hashing matrices to partition keys across cluster nodes with minimal re-mapping. Compilers utilize hash tables for instantaneous symbol lookup.
