# Exam-Oriented 320-Slide Presentation Deck Plan (80 Slides per Module)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create a comprehensive, exam-oriented 320-slide presentation deck (80 slides per module) for PCCST303 (Data Structures & Algorithms) covering KTU syllabus, previous year questions (PYQs) with step-by-step solutions, mark distributions, formulas, and real-time interactive switching across all 10 liquid glass theme effects.

**Architecture:**
1. Generate complete 320-slide dataset (`courses/PCCST303/slides/exam_slides_320.json` & `exam_slides_data.js`) using Python script `scripts/generate_exam_slides.py` with 80 slides for Module 1, 80 for Module 2, 80 for Module 3, and 80 for Module 4.
2. Upgrade `courses/PCCST303/slides/lecture_slides.html` to support:
   - Real-time switching across all 10 Liquid Glass themes (`theme-liquid`, `theme-frosted`, `theme-aurora`, `theme-crystal`, `theme-holographic`, `theme-translucent`, `theme-neumorphic`, `theme-scifi`, `theme-academic`, `theme-highcontrast`).
   - Module filter buttons: `[Module 1 (1-80)]`, `[Module 2 (81-160)]`, `[Module 3 (161-240)]`, `[Module 4 (241-320)]`.
   - Slide jump input & progress bar with percentage.
   - Tag filters (`Part A 3M`, `Part B 9M`, `Numericals`, `PYQ Solutions`, `Algorithms`).
   - Keyboard navigation (Left, Right, Space, Home, End).
   - High-contrast print-to-PDF layout.
3. Update embedded slide player in `courses/PCCST303/website/index.html` to load and navigate the 320 exam slides.
4. Update `scripts/build_all_courses.py` to support the expanded slide deck.
5. Verify via automated tests and browser visual inspection.
6. Commit to Git and deploy to Vercel production using Windows Credential Manager.

**Tech Stack:** HTML5, Vanilla CSS (Liquid Glass), JavaScript, SVG, Python, Vercel CLI.

- University examination orientation (KTU 2024 Scheme, Part A 3-mark questions, Part B 9-mark questions, step-by-step derivations, marking rubrics).

## Tasks

### Task 1: Generate 320 Exam-Oriented Slides Data
- [ ] Create `scripts/generate_exam_slides.py` that generates 320 rich slides:
  - Module 1 (Slides 1-80): Asymptotic bounds proofs, Master theorem cases, polynomial arrays, sparse matrix 3-tuple & fast transpose, stack ADT, multi-stacks, infix-to-postfix shunting-yard algorithm, postfix evaluation, queue ADT, circular queue arithmetic, deque, solved KTU PYQs.
  - Module 2 (Slides 81-160): Singly linked list operations, pointer rewiring, reversing SLL (iterative & recursive), cycle detection, polynomial SLL, doubly linked list 4-way pointer manipulation, circular linked list, dynamic memory allocation (First-Fit, Best-Fit, Worst-Fit), fragmentation formulas, garbage collection (Mark-and-Sweep, Reference counting, Stop-and-Copy), solved KTU PYQs.
  - Module 3 (Slides 161-240): Tree terminology & properties, binary tree representations, traversals (preorder, inorder, postorder, level-order, non-recursive), tree reconstruction, expression trees, BST search/insert/3-case deletion with Inorder Successor, binary heaps bottom-up build-heap $O(n)$ proof, priority queues, graphs adjacency matrix vs list, BFS, DFS, cycle detection, topological sort, solved KTU PYQs.
  - Module 4 (Slides 241-320): Comparison sorting (Selection, Insertion, Quick sort Lomuto/Hoare, recurrence analysis, Merge sort, Heap sort), non-comparison Radix sort, linear & binary search logarithmic bounds, hashing functions (Division, Mid-square, Folding, Digit analysis), collision resolution (Linear probing, Quadratic probing, Double hashing, Separate chaining), load factor $\alpha$ formulas, solved KTU PYQs, and 60-mark KTU exam strategy.
- [ ] Execute script to produce `courses/PCCST303/slides/exam_slides_320.json` and `courses/PCCST303/slides/exam_slides_data.js`.
